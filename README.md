# Monica's Sweet Makings — Website Concept

An unofficial small-business website concept created to help a friend communicate her products, event services, and story more clearly online.

[View the live concept](https://hyperwumpus.github.io/Monica-Sweets/)

> This is a portfolio prototype in active development. Business details, images, pricing, and ordering information require the owner's approval before launch.

## Why I made it

This project began with a person and a problem, not a class assignment. I wanted to help a friend facing a difficult season see what her business could become with a clearer brand, a welcoming storefront, and a simpler path for customers to place an order.

## Highlights

- Warm, handcrafted visual identity
- Mobile-friendly product presentation
- Product and service sections
- Event-focused calls to action
- Story-led design intended to build trust
- Lightweight single-page implementation
